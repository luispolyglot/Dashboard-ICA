# Integration Tests (Supabase Local)

These tests run against a real Supabase database and validate daily metrics writes, RPC behavior, and write locks.

## 1) Start local Supabase

```bash
supabase start
```

## 2) Export required env vars

```bash
export SUPABASE_URL="http://127.0.0.1:54321"
export SUPABASE_ANON_KEY="<your-local-anon-key>"
export SUPABASE_SERVICE_ROLE_KEY="<your-local-service-role-key>"
```

You can get the keys from your local Supabase stack status output (`supabase status`) or your local `.env` generated by Supabase.

## 3) Run tests

```bash
npm run test:integration
```

## Notes

- Tests create users with random email/password automatically.
- Tests clean up created users at the end.
- Run migrations before tests so the RPCs and policies exist.
